Transient memory per pass (MiB)

Render graph transient memory in use while each pass executes, in frame execution order (last measured frame). Resources are allocated at the start of their first pass and released at the end of their last pass, so both passes count them. Orange: compare reference (last baseline run, or the selected run). Dots mark passes with different usage or allocations; in the tooltip, orange events are not in the compare run and struck through ones exist only there. Click a pass to select it.

Transient resources

Every transient allocation of the frame, largest first. Hover to show its lifetime on the chart, click to select the allocating pass.

Pass hashes vs golden

Hashes of all outputs of every render graph pass in the golden frame, rendered with transient resources cleared. The first mismatching pass is usually the source of a difference.
